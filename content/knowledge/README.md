# База знаний живого поиска

`facts.jsonl` — проверенные факты о кальянной культуре и рынке. Поиск читает их наряду с вики, правилами и объявлениями. Страница сайта из файла не строится, факт виден только в ответе и хронике со ссылкой на источник.

## Как пополнять

1. Брать только источники, где `robots.txt` разрешает доступ, в том числе ИИ-сборщикам (`ClaudeBot`, `GPTBot`, `CCBot`). Запрет и блокировку не обходить. HTReviews запрещает такой доступ, поэтому не используется.
2. Страницу читать целиком, факт записывать своими словами, по-русски, одним предложением.
3. Для каждого факта держать дословную цитату. Сборка отклоняет факт, если цитаты нет на скачанной странице или рядом с ней нет указанного года. Цитаты в опубликованный файл не попадают.
4. Спорное приписывать источнику: «по данным компании», «магазин называет». Даты из блогов магазинов не считать установленными, расхождения сохранять отдельными фактами.

5. Обсуждения VK (`vk.com/board24`, `vk.com/board905`) брать как датированные свидетельства участников: без их имён, с формулировкой «участники обсуждали». Читать только через браузер агента, медленно. Токены через чужие приложения VK не выпускать.

## Что не брать

- Вкусы, крепость, никотин, цены, рейтинги и сравнения табака, советы по покупке.
- Контакты, адреса, дату рождения, семью и прочие личные сведения. О людях только публичная профессиональная деятельность.
- Обвинения, скандалы и неподтверждённые истории о живых людях.
- Сайты-клоны и SEO-страницы: только заранее выбранные источники.

## Поля

`entity`, `aliases` — о чём факт и как это ищут. `type`: history, brand, person, community, product, trend, market, regulation, research. `year` — год или `null`. `source.kind`: encyclopedia, official, research, press, community, blog, retailer. От `kind` зависят вес в поиске и пометка для модели.

Маршруты запросов находятся в `src/server/live-search/router.ts`, инструкции модели в `src/server/live-search/prompts.ts`.
