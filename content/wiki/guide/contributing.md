# Как редактировать Shisha Market Wiki

Исправление или первоисточник можно прислать через [форму предложений](/support#suggest) без работы с Git. Укажите адрес статьи, спорный фрагмент, исправление и ссылку, которая подтверждает факт. Код вики хранится в файлах Markdown; вклад в статьи разрешён по CC BY-SA 4.0.

## Исправление без Git

Откройте форму предложений и опишите одну конкретную правку. Для названия модели, истории марки и совместимости нужен первоисточник: сайт изготовителя, руководство или датированный официальный документ. Реклама магазина и повторяющие друг друга пересказы не подтверждают факт автоматически.

Не отправляйте персональные данные, коды входа или чужие фотографии без разрешения.

## Быстрый старт

Если [репозиторий](https://github.com/vixkosla/shisha-market) доступен вашему аккаунту, можно предложить Pull Request. Если ссылка не открывается, воспользуйтесь формой выше: доступ к документам и возможность прислать исправление не должны зависеть от GitHub.

1. **Форкните репозиторий** — нажмите кнопку «Fork» на странице [github.com/vixkosla/shisha-market](https://github.com/vixkosla/shisha-market)
2. **Склонируйте свой форк** — `git clone https://github.com/YOUR_USERNAME/shisha-market.git`
3. **Создайте ветку** — `git checkout -b wiki/my-article`
4. **Отредактируйте файлы** — все статьи находятся в `content/wiki/`
5. **Запомните изменения** — `git add . && git commit -m "Add article about..."`
6. **Отправьте в свой форк** — `git push origin wiki/my-article`
7. **Создайте Pull Request** — на странице вашего форка нажмите «New Pull Request»

```

├── brands/                     # Статьи о производителях
│   ├── kaloud.md
│   ├── oduman.md
│   └── ...
├── categories/                 # Статьи о категориях
│   ├── hookahs.md
│   ├── bowls.md
│   └── ...
└── guide/                      # Руководства
    └── contributing.md         # Этот файл
```

## Стиль оформления

### Заголовки
```markdown
# Название статьи

## Раздел

### Подраздел
```

### Таблицы
```markdown
| Колонка 1 | Колонка 2 |
|-----------|-----------|
| Значение 1 | Значение 2 |
```

### Ссылки
```markdown
[Текст ссылки](relative/path.md)
```

### Списки
```markdown
- Элемент списка
- Ещё один элемент

1. Нумерованный список
2. Второй пункт
```

## Правила

1. **Нейтральный тон** — пишите как энциклопедия, без рекламы
2. **Проверяемые факты** — для характеристик, истории и совместимости указывайте первоисточники и дату проверки
3. **Русский язык** — все статьи на русском
4. **Без копирайта** — не копируйте тексты с других сайтов
5. **Актуальность** — обновляйте устаревшую информацию

## Добавление новой статьи

1. Создайте файл в соответствующей директории (`brands/`, `categories/`)
2. Назовите файл строчными буквами с дефисами: `my-brand.md`
3. Добавьте ссылку на статью в `index.md`
4. Создайте Pull Request

## Редактирование существующей статьи

1. Найдите файл в соответствующей директории
2. Отредактируйте содержимое
3. Создайте Pull Request с описанием изменений

## Модерация

Все Pull Requests проверяются перед слиянием. Убедитесь, что ваши изменения:
- Не содержат рекламы
- Не нарушают авторские права
- Соответствуют стилю вики
- Нейтральны по тону
