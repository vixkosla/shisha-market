# Атлас брендов и устройств

Структурный слой живого поиска: бренд, затем линейка, затем модель и артикул. Сейчас заполнен первый уровень, `brands.json`. Когда запрос называет бренд, рядом с ответом появляется справка: логотип, проверенные строки и легенда.

## Правила

1. Только кальяны, чаши, устройства, аксессуары, заведения и сервисы. Табачных брендов в атласе нет: справка с логотипом для них была бы рекламой табака.
2. Каждая строка `rows` и каждая строка `legend` ссылается на id факта из `content/knowledge/facts.jsonl`. Факта нет, значит нет и строки. Легенда, которую компания рассказывает о себе, показывается с пометкой «по версии компании».
3. Логотип берётся только с официального сайта, если его `robots.txt` разрешает доступ, в том числе ИИ-сборщикам. Файл кладётся в `public/brand-logos/<slug>.png`, а в поле `logo.source` записывается адрес, откуда он взят. Логотип — товарный знак владельца, используется только чтобы указать на бренд. Если правообладатель попросит, логотип убирается и вместо него выводится название шрифтом.
4. `plate` задаёт фон под логотипом: `light` для тёмных знаков, `dark` для светлых.
5. `aliases` — как бренд пишут в запросах, в нижнем регистре, латиницей и кириллицей. Псевдоним совпадает с началом слова, поэтому «калауда» находит Kaloud.

## Следующие уровни

Линейки и модели с артикулами и характеристиками из официальных каталогов, затем привязка объявлений к модели по названию.

## Справочник марок `makes.json`

Шире атласа и проще его: 196 марок кальянов, чаш, калаудов (HMD), шлангов и аксессуаров с моделями, как их называют каталоги магазинов. Нужен форме объявления (подсказки марки и модели, распознавание по названию) и поиску. Строк из базы фактов у этих записей нет, справка показывает только вид товара, модели из каталогов, страну, если магазин её указывает, и ссылки на каталоги.

Собран 11.11.2026 из каталогов шести магазинов, у каждого перед чтением проверен `robots.txt` (ИИ-сборщики не запрещены): Hookah Vault и hookah.com (США), Shanti (Чехия), Epicentr (Украина), Onliner (Беларусь), mykalyan.ru (Москва). Исходник — `scripts/build-makes.py`, файл пересобирается им.

- Табачные марки не включаются, даже если у них есть чаши или кальяны (Darkside, Tangiers, Fumari, Starbuzz, Black Burn, Bonche, WTO, Element, Deus и подобные).
- Электронные кальяны и никотиновые устройства не включаются.
- Не марки: названия моделей и материалов (Lotus, Soft Touch), безымянные фабрики, названия магазинов.
- `match: false` — название совпадает с обычным словом («Душа», «Пушка», «Форма»): марка есть в подсказках, но по тексту не угадывается. Псевдонимы, похожие на обычные слова («грамм», «грин», «макс»), не добавляются.
- Если марка есть и в `brands.json`, записи сливаются: строки, логотип и легенда — из атласа, модели и каталоги — из справочника.
